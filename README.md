# 爆速シフトくん — 障害児入所施設 月間シフト作成（パイロット版）

障害児入所施設の月間職員シフト表を、配置基準・労務ルールの警告表示付きでブラウザ上で作成できるパイロット版です。ビルド不要（Vanilla JS / ES Modules）、GitHub Pages でホストしています。

## 注意（パイロット版の制約）

- **データはブラウザの localStorage にのみ保存されます。** サーバーはなく、認証もありません。別の端末・別のブラウザからは同じデータを見られません。
- 実際の職員の個人情報は入力しないでください。まずはサンプルデータで操作感を確認するためのものです。
- サイドバーの「権限」から**管理者モード / 職員（閲覧のみ）モード**を切り替えられます。職員モードでは希望休の申請（★ボタン）以外の入力ができません。ただしPINによる簡易的な制限で、本格的なアクセス制御ではありません（開発者ツール等で回避可能）。
- 本番利用に進む場合は、サーバー保存・本格的な認証・複数拠点対応などを別途実装する必要があります。

## できること

- 職員マスタ（氏名・職種・ユニット・常勤区分・資格・育児短時間勤務・深夜業免除・**対応可能な勤務パターン**）の管理
- 勤務パターンの管理（最大10種類、時間帯・休憩・必要人数・資格者最低人数）
- 月間シフト表をグリッドで作成（プルダウンで割当、セル左の★ボタンで希望休をON/OFF）。プルダウンにはその職員が対応可能な勤務パターンのみ表示されます
- **自動作成**：希望休と各種要件（配置基準・資格・夜勤明け休み・11時間インターバル・週40時間・月間休日数・対応可能な勤務パターンなど）をもとに、未入力のセルだけを自動で埋める機能。入力済みのセルは上書きしません。要件を満たせない箇所は空欄のまま残し、警告として表示します（無理な辻褄合わせはしない設計）
- サイドバーの「マニュアル」から使い方・警告の見方・自動作成の考え方を確認できます
- 依頼書 No.1〜18 のうち、日々のシフトデータから機械的に判定できる項目をリアルタイム警告表示
  - 配置基準 / 資格者最低人数 / 児発管の日次配置 / 夜間配置
  - 夜勤明けの翌日休み・勤務間インターバル11時間・7日以上の連続勤務
  - 週40時間超過分の時間外集計・月間36協定上限超過
  - 深夜時間帯（22:00〜翌5:00）を含む勤務への深夜業免除対象者の割当
  - 育児短時間勤務者の上限超過
  - 希望休が申請されているのに勤務が割り当てられているケース
  - 月間休日数の目安（30日→9日以上/31日→10日以上）
- 印刷・PDF出力（ブラウザの印刷機能を利用）

### 目視確認が必要な項目（自動判定していないもの）

常勤要件の充足（No.3）、看護師の適切配置（No.5）、ユニットごとの安全配置（No.7）、変形労働時間制の枠内管理（No.9）、年5日の年休取得義務（No.16）などは、今回のパイロットでは自動チェックの対象外です。ダッシュボードの集計値を参考に、管理者が最終確認してください。

## ローカルで動かす

ビルド不要です。`index.html` を静的サーバーで配信するだけで動きます（ES Modules を使っているため `file://` では動かないブラウザがあります）。

```bash
python3 -m http.server 8000
```

またはお好みの静的サーバーで `index.html` を配信してください。

## 技術構成

- Vanilla JavaScript（ES Modules）/ HTML / CSS、ビルドツールなし
- 状態管理・永続化：`localStorage`
- ホスティング：GitHub Pages
